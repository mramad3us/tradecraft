# Pipeline

How the game's content gets made: which tool for which job and why, what each licence allows, the recipes, and what we've learned along the way. This changes as we learn. When a tool choice changes, or something surprises us, it's written here in the same change (see Lessons).

## How a tool gets picked

In order:

1. **Real before generated.** If a CC0 library has the thing (a photographed brick wall, a scanned chair, a real sky), use it. It's physically right, it tiles, it comes with the full set of PBR maps (colour, roughness, normal), and it has no generative oddities. Generate only what no library has: in-world signs and posters, a specific wallpaper, portraits, one-off set dressing.
2. **A script, never a hand edit.** Scenes, kits, people and image batches are scripts in the repo, so they can be rebuilt, varied and fixed at the source.
3. **The least restrictive licence that does the job.** CC0 / Apache-2.0 first, then CC-BY (credited), then the non-commercial models the free game is allowed (Licences, below).
4. **Local before hosted.** Unlimited, free, private, and reproducible from model + prompt + seed. Hosted inference through Hugging Face is metered ($0.10 a month free, 2026-10-25), and the provider can change the model under us. Hosted is for a model too big for this Mac, and only by decision.
5. **Every shipped asset says where it came from** (Provenance, below).

## Which tool for which job

| Job | First choice | Otherwise | Why |
|---|---|---|---|
| People (bodies, faces, clothes, hair) | MPFB, `tools/blender/person.py` | — | Parametric and varied (age, build, ethnicity), contemporary wardrobe, rigged, CC0/CC-BY with per-asset credits |
| People in motion | CMU motion capture: `tools/fetch-cmu.sh`, then `person.py --motions` | Mixamo (the user's Adobe login; MPFB has a `mixamo` skeleton); Quaternius (CC0, needs retargeting) | 2,435 recorded motions of real people, free, no account, and the same bone names as MPFB's `cmu_mb` skeleton |
| Buildings and rooms | The shell (walls, floors, roof, interior walls, openings) is built at runtime from a short description (`samples/lib/building.js`). | Street furniture | Poly Haven models (CC0) | Blender kit pieces | Scanned, real-world scale |

| Exploring a look before committing | Any of the above; Qwen-Image 2.1 too | | Qwen never ships (licence) |

| Comparing samples | ImageMagick contact sheets (`magick montage`) | | One picture of many options |
| Motion review | ffmpeg from screenshot frames | | Clips, not stills |

## Licences

Anything that ships is CC0, CC-BY (credited in `CREDITS.md` in the same change), or generated by a model allowed below. Nothing else. The game is free and won't be sold (the user, 2026-10-25), which is what lets the non-commercial models in. If that ever changes (a price, donations, ads), the provenance records say what to regenerate.

| Model (mflux command) | Licence (read 2026-10-25) | Images may ship? |
|---|---|---|
| Z-Image-Turbo (`mflux-generate-z-image-turbo -q 8`) | Apache-2.0 | Yes |
| FLUX.2 klein 4B (`mflux-generate-flux2 -m flux2-klein-4b`, `-flux2-edit`) | Apache-2.0 | Yes |
| FLUX.2 klein 9B (`-m flux2-klein-9b`), FLUX.1 dev family | FLUX Non-Commercial v2.1: "hobby projects" with no payment are non-commercial; outputs usable "for any purpose" | Yes |
| Krea 2 Turbo (`mflux-generate-krea2`) | Krea 2 Community: "You own all Outputs"; even commercial use below $1M a year; needs a content filter, and human review counts | Yes |
| Ideogram 4 (`mflux-generate-ideogram4`) | Ideogram Non-Commercial: "hobby project[s]" with no revenue; no rights claimed in outputs; no real military or surveillance use (art for a spy fiction isn't that) | Yes |
| Qwen-Image 2.1 (`mflux-generate-qwen-2.1`, `-qwen-2.1-edit`) | Qwen Research: "research or evaluation purposes only" | **No: samples only** |
| Anything else (FIBO, ERNIE, Lens, SeedVR2…) | Not read yet | Read it first, add it here |

The gated models (FLUX.2 klein 9B, Krea 2, Ideogram 4) download with the user's Hugging Face token, kept in `~/.cache/huggingface/token`, never in the repo and never printed. Before anything generated ships: review it for recognisable brands, logos, real people, or anything unlawful (that's also Krea's required content filter).

Asset libraries: MakeHuman packs (CC0 and CC-BY: `tools/blender/mpfb-packs.txt`), Poly Haven and ambientCG (CC0), and the CMU Graphics Lab Motion Capture Database ("free for use in research and commercial projects worldwide", acknowledged in CREDITS.md; cgspeed's BVH conversion, from the GitHub copy Shriinivas/cmubvh).

## Provenance

Next to every asset that ships, a sidecar `.json` with the same name records how to make it again:
- people: `<name>.credits.json`, written by `person.py`: the spec, and every asset's author, licence and source;
- generated images: `<name>.gen.json`: the model, the full command (prompt, seed, steps, size, quantisation), the mflux version, and any reference images;
- library assets: `<name>.source.json`: the library, asset id, licence and URL.

## Recipes

- **Set up everything:** `tools/setup.sh` (rerunnable).
- **A person:** `blender -b --python tools/blender/person.py -- --spec spec.json --out samples/x/person.glb` (`--list clothes|hair|skin|…` shows what's installed; `--raw` skips the optimising).
- **Motion:** `tools/fetch-cmu.sh --find walk` searches the index (every word must match). `tools/fetch-cmu.sh 07_01 18_08` caches clips. `person.py … --motions 07_01,18_08@0-8` bakes them on (`@start-end` in seconds takes a slice), and they come out as named animations at 30 fps.
- **Checking motion:** `samples/001-motion/` plays the clips. `?check` reports each clip's speed, facing (feet against heading: 1 is forward) and planted-foot slide (m/s: under about 0.15 is fine at game distance). `?strip=t1,t2,…` is a filmstrip, `?orbit=deg,dist,up&focus=<bone>` a close-up.
- **An image:** `tools/gen.sh <model> --out x.png --prompt "…" [--seed N --width W --height H --steps 9]`. Always through `gen.sh`, never mflux directly. It runs from a saved 8-bit copy of the model (made once, in `~/Library/Caches/tradecraft/models/`), and it writes `x.gen.json` (model, licence, prompt, seed, command, date). The first use of a model downloads it to `~/.cache/huggingface` (Z-Image-Turbo: about 33 GB) and saves the copy (about 10 GB).
- **From the CC0 libraries:** `node tools/fetch-asset.mjs find polyhaven textures|models|hdris <words>`, or `find ambientcg <words>`. Then `get polyhaven <id> [--res 1k|2k]` or `get ambientcg <id> [--res 1K|2K]`. It lands in `assets/lib/<library>/<id>/` with its `.source.json`. Textures arrive as `<id>_diff|nor_gl|rough|ao_<res>.jpg`, models as one game-sized `.glb` (`--raw` keeps the original), skies as `.hdr`. `samples/002-library/` shows how to use them: tiling at real size, the sky as the environment light.
- **The building kit:** `blender -b --python tools/blender/kit.py -- --out assets/kit/kit.glb`. Each piece is a top-level node, with glTF extras `kind`, `opening` [w, h] and `sill`. Its origin is the bottom middle of the opening in the wall's mid-plane, and it faces out of the wall (+Z).
- **A building:** `building(kit, spec)` from `samples/lib/building.js` (the spec format is in its header). Then `update(camera, { walls: 'up'|'cut'|'down', storey })` for the cutaway. Materials come from `textured('<library>/<id>', metresPerTile)` in `samples/lib/materials.js`, with `await loaded(draw)` before `ready()`. `samples/003-building/` is the worked example.
- **A screenshot:** serve (`python3 tools/serve.py <port> .`), then `node tools/shot.mjs <url> <out.png> [--size WxH]`; kill the server afterwards. Samples take `?cam=px,py,pz,tx,ty,tz`.

## Still needed

- **Motion for the game itself** (the samples can do without): loops cut from the clips, walks in place with the travel given to the game's movement, blending between them. And the hands: the `cmu_mb` skeleton has only three finger bones per hand, so a hand is a relaxed curl, not a grip.
- **More kit:** roofs that aren't flat, awnings, cornices, shutters, signs, street lamps, interior fittings (kitchens, bathrooms). And kit pieces merged by material when cloned (each is several meshes today: more draw calls than needed).
- **The samples gallery:** one page listing every sample with a picture, and contact sheets, so the user can pick.
- Later: sound (effects, ambience, music), UI fonts (vendored, offline), compressed GPU textures (KTX2), portraits.

## Lessons

- *2026-10-25.* A kit piece with no hole of its own (a balcony) must not be treated as an opening: a zero-height "hole" made the wall-splitting rebuild the wall across the French window behind it.
- *2026-10-25.* Not every ambientCG set has every map (plaster, concrete and tiles come without AO): `textured()` loads only what the set's `.source.json` lists.
- *2026-10-25.* three's GLTFLoader turns `.`, `:`, `/` and `[]` in node names into `_`. Kit pieces are looked up by their root names, which have none.

- *2026-10-25.* MPFB's MAKESKIN materials give clothes, hair and brows a clear coat, and the suit a glossy roughness map: cloth shone like vinyl under an environment light. `person.py` keeps the coat only on the eyes, and sets cloth matte (0.85), shoes 0.55, hair 0.6, skin 0.55.
- *2026-10-25.* Poly Haven's API terms: free for any use, commercial included. Downloaded CC0 assets need no credit, ever; only an app showing content from the live API owes a "Powered by Poly Haven" line. Calls must carry a recognisable User-Agent (`fetch-asset.mjs` does).
- *2026-10-25.* In a sample, don't rely on `THREE.DefaultLoadingManager.onLoad`: textures that finish before it's set never fire it. Wait on each texture's own promise.

- *2026-10-25.* mflux's `-q 8` quantises at load time, which means loading full precision first. Z-Image-Turbo peaked at 25 GB on this 24 GB Mac and swapped hard. From a copy saved with `mflux-save` it peaks at 7.5 GB and takes 32 s for 1216×832 at 9 steps. `tools/gen.sh` always runs from the saved copy.
- *2026-10-25.* Z-Image-Turbo is strong at realism (a rainy street corner at dusk, a lived-in kitchen) but garbles text ("Pian0 Recital", "Europan Ricitat"). Anything with words goes to Ideogram 4. Image models don't draw cutaways either: that's the 3D renderer's job.

- *2026-10-25.* cgspeed's CMU BVH files start with a calibration frame (all rotations zero): skip it. Their rest pose is a T-pose with the legs splayed about 20°, not MakeHuman's straight-legged A-pose (nor MPFB's own T-pose), so `retarget.py` first swings the person's bones to point as the clip's do at rest, then transfers rotations from there. It scales the hips' travel by thigh + shin length, not by "hips to foot" (the splayed legs made that 12% short). Planted-foot slide went from 0.37 to 0.12 m/s.
- *2026-10-25.* The CMU conversion has no real hand data (the wrists are noise, the fingers never move): the hand follows the forearm, and the fingers take a 35° curl about their local Z, +Z on the right and −Z on the left.
- *2026-10-25.* Blender's scene defaults to 24 fps and the glTF exporter samples actions at the scene rate: set it to the rate the keys were made at (30), or clips play 25% slow.
- *2026-10-25.* CMU's "walk stealthily" (17_03, 17_04) is a theatrical, arms-out cartoon sneak: not grounded. Prefer ordinary walks, pauses, glances, and the two-person conversations (18_08 with 19_08, recorded together).
- *2026-10-25.* zsh (the shell here) doesn't split an unquoted `$v` into words: `for v in "X 0"; do set -- $v` gives one argument. Spell the pairs out in loops.

- *2026-10-25.* MPFB's materials all wire the texture's alpha, so Blender exports every one as BLEND. A blended body hides nothing behind it, and the mouth's inside and the eyeballs' backs showed through the face. `person.py` sets skin and eyes OPAQUE, and the rest MASK with soft edges (alpha to coverage).
- *2026-10-25.* Pillow 13.0 (2026-10-16) imports a lazy-loading feature that Python 3.13/3.14 lack, and mflux died at start. Pinned Pillow 12.3.0 (`tools/setup.sh`).
- *2026-10-25.* Blender 5 imports extensions as `bl_ext.<repository>.<id>`: MPFB is `bl_ext.blender_org.mpfb`. Syncing the extension list needs `--online-mode`.
- *2026-10-25.* Headless Chrome renders WebGL on the GPU with `--use-angle=metal` (ANGLE Metal on the M5 Pro), so screenshots show what the player sees.
- *2026-10-25.* MakeHuman pack downloads run about 1 MB/s per connection; four in parallel get about 4 MB/s.
