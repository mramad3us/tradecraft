# Credits

Third-party work that ships with the game. CC0 needs no credit but is listed when it's a whole kit; CC-BY must be: the asset, its author, the licence and where it came from, added in the same change that brings the asset in.

## Code

- [three.js](https://threejs.org) 0.186.1, MIT (`vendor/three/LICENSE`).

## Assets

People are made with [MPFB](https://static.makehumancommunity.org/mpfb.html) from MakeHuman community assets; each model's `.credits.json` lists every asset it uses. The CC0 ones need no credit. The CC-BY ones:

- "Shoes Oxford male" by Mindfront, CC-BY, http://www.makehumancommunity.org/node/620 (`samples/000-toolchain/person.glb`).

## Motion

Movement comes from the CMU Graphics Lab Motion Capture Database: "The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217." It uses cgspeed's BVH conversion (B. Hahne), from the GitHub copy at https://github.com/Shriinivas/cmubvh.

## AI-generated images

Some of the game's images are, or will be, generated on the developer's machine with open-weight image models. Each one is listed next to it with its model, prompt and seed.
